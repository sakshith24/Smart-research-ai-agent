# Smart Research AI Agent

An AI-powered research assistant built using LangGraph, LangChain, and OpenAI.

## Features

- React AI Agent
- Tool Calling
- Real-time Web Search (Tavily)
- Cryptocurrency Price Lookup (CoinGecko API)
- Conversation Memory

## Tech Stack

- JavaScript
- Node.js
- LangChain.js
- LangGraph
- OpenAI GPT-4o-mini
- Tavily Search API
- CoinGecko API

## Installation

npm install

## Run

npm start

## Environment Variables

OPENAI_API_KEY=
TAVILY_API_KEY=
